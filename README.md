# Nupur Jadhav — Responsive Portfolio1

A mobile-first portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling and responsive breakpoints
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing
Check that the listed project repositories exist under your GitHub account. If a project repository has not been transferred or recreated under `jadhavnupur60-dev`, update that project's link in `index.html`.

## Publish with GitHub Pages
Push these files to a GitHub repository, then go to Settings → Pages. Select “Deploy from a branch”, choose `main` and `/(root)`, and save.
